AgentNodify for macOS — installation notes

Open the .pkg in Installer and follow its prompts. The package installs only
/Applications/AgentNodify.app. Administrator authorization may be required.
Qt, examples and license texts are inside the application bundle's Resources.
Agent CLIs, Python and Node.js are not installed by this package.

Quit AgentNodify using File > Quit or its menu-bar icon before upgrading or
removing it. Closing a window alone does not terminate the application.
To uninstall, move AgentNodify.app to Trash. Settings, flows, history, external
projects and agent CLI authentication data are intentionally not removed.
macOS may keep an installer receipt; it does not hold application user data.

The application has only an ad-hoc signature. The PKG has no Developer ID
Installer signature and is not notarized. Gatekeeper may block it. Do not
disable system security checks or remove quarantine automatically.

Package generation is not public-distribution approval. Before publishing,
review the actual Qt distribution and all bundled third-party libraries, their
licenses, corresponding sources, build information, Developer ID signing and
notarization. The Windows source profile does not cover macOS/Homebrew binaries.
